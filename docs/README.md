# 项目文档

按职能查阅；针对某个问题的修改说明和验收图片集中放在同一个问题文件夹。

| 分类 | 内容 |
| --- | --- |
| 产品 | [需求文档](./产品/需求文档.md)：业务范围、角色与功能要求 |
| 技术 | [技术设计](./技术/技术设计.md)：架构、数据与部署方案；[本地开发与验收](./技术/本地开发与验收.md)：共用环境准备 |
| 评审 | [代码审查与现场审核改进建议](./评审/代码审查与现场审核改进建议.md)：保留审查时的发现 |
| 问题整改 | [问题目录与进度](./问题整改/README.md)：逐项复现、修改、验收与截图 |

## 存放方式

```text
docs/
├─ README.md
├─ 产品/
│  └─ 需求文档.md
├─ 技术/
│  ├─ 技术设计.md
│  └─ 本地开发与验收.md
├─ 评审/
│  └─ 代码审查与现场审核改进建议.md
└─ 问题整改/
   ├─ README.md
   ├─ 01-同名宾客自动串档/
   ├─ 02-通用回执覆盖专属回执/
   ├─ 03-重复签到与重复记账/
   ├─ 现场临时宾客重名无法登记/
   ├─ 登录需要输入两次账号密码/
   └─ 本地请柬链接指向示例域名/
```

每个问题文件夹内放 `README.md` 和对应验收图片。新增整改继续沿用[问题记录约定](./问题整改/README.md#记录约定)。旧的《逐项整改与验收》已拆分到问题目录，原有验证结果和截图均随问题归档。
