## 后续维护

新阶段的一次性记录可以继续归档，但现行规则只改当前文档，实际验收只记测试报告。不再在旧问题目录追加新的业务需求，也不再沿用“第N轮优先”的歧义口径。

本地截图或二维码样张不代表线上验收，localhost图片不可分发或送印；含婚纱照的文件仍按私人资料保管。部分历史设计稿只以当时本机路径或文件名记载，归档不会补造不存在的设计源文件。
