## 发现与修复

| 问题 | 处理 | 验证证据 |
| --- | --- | --- |
| 短手机窗口同时堆叠审核队列和名单，表体只剩约 1px | 小于 768px 时用原生 Segmented 切换待审/名单；两个模块继续挂载，保留搜索及分页。现场概览由按钮展开 Popover | 390×640 表体约 85px；队列单独可用，键盘方向键可切换，来回切换保留搜索；桌面仍为 26:74 Grid |
| 审核长分组将个别数据行从约 53px 撑到 83px | 姓名按钮单行截断并支持 hover/focus Tooltip；分组、备注复用 TableText；本功能行高统一 56px | 两角色、四窗口长姓名/分组/换行备注行高一致，完整内容可查看 |
| 工作人员回执及详情出现 null 人数 | 本功能只读格式明确表示“人数未记录”“儿童人数未记录” | 未知值不推算为 0，列表与详情不再输出 null/undefined 人数 |
| 历史读取失败只能关闭后重开 | 共用历史弹窗增加原处重试 | 首次失败后恢复接口，弹窗内成功读取历史 |
| 生命周期弹窗填写原因后，关闭会丢失输入 | 复用 useUnsavedChanges；取消/Esc 可继续填写或明确丢弃；保存中仍禁止关闭 | 继续填写保留原原因，明确丢弃后关闭；原原因校验、影响预览及提交 token 不变 |
| 退出请求失败无可见反馈，并产生未处理异常 | 保留原注销、清缓存、跳转顺序；增加重复请求锁、进行中状态及常驻失败反馈/重试 | 快速双击只请求一次；失败仍留当前页，重试成功后到登录页，无未处理页面异常 |
| 原生 Typography 样式覆盖长账号的最大宽度 | 使用本项目账号容器限定选择器，保持省略及 Tooltip | 390px 下用户名最大 192px，操作入口可见，页面无横向溢出 |
| 登录卡片固定 360px，在 320px 撑开隐式 Grid | 限定 Grid 最小列宽与卡片最大宽度 | 320px 页面不再出现原先约 376px 的横向宽度；登录请求与校验不变 |

## 交互与业务回归

- 原生抽屉的 Tab 不进入背景操作；关闭后焦点回到原入口。保留浏览器工具栏的原生键盘行为，没有自造焦点锁。
- 审核空态在可视内容区水平、垂直居中，测量偏差小于 1px；空列表与连接失败分开表达。九类列表的失败重试在 390×640 下可达，恢复后可在原页继续操作。
- 礼金更正、作废/恢复、原因必填、失败输入保留、预览 token 刷新、筛选保留、工作人员入口回归通过。
- 审核候选后台刷新保留手填人数；退出待审队列后禁止旧确认；失败重试保持幂等键；同名选择按 ID；工作人员不请求管理员统计。
- 新的操作原因保护只影响关闭反馈；没有更改 API、数据结构、权限、人数/金额解析、业务校验或生命周期规则。
