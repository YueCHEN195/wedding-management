# 婚礼物料生成与下载

更新日期：2026-10-23。维护当前输出规格、素材映射与验收边界；历史确认稿对照和本地样张见[归档](../归档/README.md)。

## 当前输出

| 内容           | 输出规格                           | 入口                         |
| -------------- | ---------------------------------- | ---------------------------- |
| 专属二维码     | 512×512px                          | 管理员宾客菜单               |
| 专属分享海报   | 1080×1920px                        | 单人海报及批量ZIP            |
| 现场公共二维码 | 640×640px                          | 公共二维码接口；后台展示物料 |
| 签到桌牌       | 1748×2480px、300ppi，A5比例        | 数据导出 → 婚礼展示物料      |
| 入口导视       | 2400×3600px、102ppi，600×900mm比例 | 数据导出 → 婚礼展示物料      |

专属海报编码对应宾客完整邀请链接；公共签到码、桌牌与导视编码 `/checkin`，不含私人邀请token。公开二维码与管理员物料管理权限保持独立。

`shared/media.ts`管理输出规格，`shared/wedding.ts`的 `outputImages`独立管理照片绑定：分享海报和导视使用窗棂合照，桌牌使用夜景烟花照。修改请柬封面/内页不能顺带改动物料照片和裁切。

## 生成与下载

- 服务端qrcode编码、Sharp本地渲染，模板使用项目静态资源；无外部图床或图片生成服务。
- H纠错、四模块静区、完整静区之外的圆角白框；中心猫头避让功能模块。尺寸不足时报错，不输出损坏的码。
- 固定模板几何保留已确认的照片、字级和留白；日期、姓名、地点读取配置并转义。
- `GET /api/checkin/materials`返回公共签到地址和预览标记；`GET /api/checkin/display?format=table|sign`返回PNG，`download=1`使用附件响应，均限管理员。
- 单人接口位于 `/api/guests/:id/qr`、`/:id/poster`；批量海报为 `/api/guests/posters/export`。
- 下载检查内容类型、服务端文件名及失败状态；不把错误JSON当成功附件。预览失败提供重试，短窗口只滚动弹窗Body。

## 分发与印刷边界

本机、示例域名、IP或非HTTPS目的地会标为预览；这个判断不证明网络可达。域名确认后必须重新生成、核对落地页，并在微信、手机和纸样上扫码。归档样张使用当时的localhost地址，仅供历史审稿，不能直接分发或送印。

照片和PNG/ZIP含私人资料，网站发布后静态照片可被访问。当前输出为RGB，无CMYK、出血或裁切标记；ppi标记不代表照片有效细节，须由印厂确认尺寸、纸材和纸样。Docker使用Noto CJK字体，容器字体外观仍需部署验收。

相关生成测试见 `tests/media-output.test.ts`，本轮实际文件验证见[一期测试报告](../测试/一期测试报告.md)。算法识码或PNG可解析不能替代真实设备及印刷验扫。
