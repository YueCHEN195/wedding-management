# 一期测试用例

业务依据：用户已确认的流程和权限，以及服务端实际契约；项目旧文档仅辅助参考。执行结果见同目录《一期测试报告》。

## 测试环境与数据

Node 24、生产构建、真实服务端、独立临时 SQLite、Chrome 无头浏览器。每个浏览器场景重置本次临时库，管理员、工作人员、宾客分别使用独立会话。禁止使用现有业务库执行以下写入。

## 重复执行

要求 Node >=24。根应用和代码检查工具按现有安装流程安装后，额外执行：

```sh
pnpm test:e2e:setup
pnpm --dir tooling/e2e exec playwright install chromium
pnpm check
pnpm test:e2e
```

也可使用本机已安装的Chrome：`E2E_BROWSER_CHANNEL=chrome pnpm test:e2e`。

浏览器测试每次先构建静态页面，再使用随机端口启动生产应用；不会启动或修改现有Vite服务。测试库在系统临时目录创建并在退出时清理。`test-results/phase1/<时间>/`记录执行结果、截图及服务日志，失败时附带Playwright trace。应用数据库路径由测试入口覆盖，种子脚本另有临时路径保护。

`pnpm check`保留原有业务回归；浏览器测试单独执行，需要本机浏览器运行环境。两者都通过才表示本用例集通过。以上验证不等于真实设备、正式部署和负载专项验收。
