# 现场签到身份选择回归

日期：2026-10-26。按用户确认的同名核对规则实施，保留原有按ID关联、幂等重试、并发冲突及未保存保护。

## 已实现规则

| 场景 | 默认与交互 |
| --- | --- |
| 无同名档案 | 隐藏身份选择，新增“临时到场”档案 |
| 只有一位未签到候选 | 默认选中，保留选择器及新增另一位同名宾客入口 |
| 多位未签到候选 | 不猜测身份，要求明确选择 |
| 同名全部已签到，无其他同名待审 | 隐藏选择，新增独立档案 |
| 有其他同名待审 | 提供原记录入口，不自动合并或新增；被另一条待审占用的档案不可选 |
| 本次扫码自动建档 | 明确来源时复用原ID，不重复建档；来源未知的历史记录仍核对 |
| 从具体宾客进入 | 保留该ID，不按同名候选顺序另选 |
| 刷新后所选档案失效 | 保留选择和人数，阻止保存并提示重新核对 |

选择已有档案带入有效出席回执人数；主动改选新增恢复1人、儿童0人。后台刷新不覆盖手填人数。
