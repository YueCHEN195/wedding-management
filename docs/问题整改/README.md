## 记录约定

- 一项问题一个文件夹，文件夹使用清晰的问题名称；来自审查报告的项目保留编号。
- 说明统一放在 `README.md`，截图与说明同目录，使用描述内容的中文文件名。
- 新增问题至少记录：原问题怎么复现、修改内容、怎么验收、实际验证结果与剩余限制。
- 状态区分“已修复并验证”和“用户验收通过”；测试数量标明当时结果，避免误认为当前项目总量。
- 共用环境步骤放在技术目录，用链接引用；原始审查结论留在评审目录，不覆盖历史发现。
