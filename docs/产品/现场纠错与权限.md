# 现场纠错与权限

2026-10-26用户确认：工作人员可直接撤销签到、作废礼金、恢复误操作，也可纠正绑错的宾客。以下操作均适用于管理员及工作人员，在现场审核原页完成。

| 情况 | 操作 | 数据规则 |
| --- | --- | --- |
| 人数录错、同行晚到、漏记儿童 | 更正人数 | 填最终实到人数，儿童包含在总人数内；不累计预计人数，不重新签到 |
| 签到后补送、分两次送礼 | 补登记礼金 | 关联指定的有效签到，新建独立一笔；重试不重复记账 |
| 金额或收款方式录错 | 更正礼金 | 只更正该笔，保留原值、原因和版本；不能用金额0表示作废 |
| 重复红包记录 | 作废礼金 | 该笔退出有效汇总，不影响签到；确认前说明金额影响 |
| 误确认、重复签到 | 撤销签到 | 仅撤销指定签到；关联礼金仍有效，需另行核对，不级联删除 |
| 无效待审 | 驳回提交 | 保留提交，可恢复到待审 |
| 撤销或作废错了 | 恢复记录 | 恢复原记录，不新建账目；签到恢复检查其他有效签到/待审及宾客归档 |
| 同名选错、认错人 | 纠正关联宾客 | 明确选择目标编号，预览源/目标及关联礼金；同一事务移动签到和其全部礼金（含作废历史），礼金版本递增；不移动其他独立礼金或回执 |

更正、撤销、作废、恢复、纠正关联均须原因和操作人记录；版本/影响范围发生变化时拒绝旧操作并保留输入。纠正关联仅支持已确认签到及已有未归档目标档案；目标有其他待审或有效签到时必须先处理冲突，不自动合并、覆盖或创建新档案。

工作人员只读取现场所需档案白名单、单笔签到和关联礼金；不能维护宾客档案、访问完整回执/祝福、全局礼金汇总或导出。独立礼金的创建、更正、作废及恢复仍限管理员。没有永久删除入口。物理退还红包等资金交接需线下核对，本系统不执行支付或退款。
